# Claude Code Instructions

## Commit messages
- Do NOT include "Co-Authored-By: Claude" or any AI attribution in commit messages.

## Plans
- When creating a plan for any non-trivial task, save it as a Markdown file with checkbox items (`- [ ]`) to the `Plans/` directory in this repo.
- Name the file descriptively (e.g. `Plans/add-feature-x.md`).
- Check off items (`- [x]`) as they are completed.
